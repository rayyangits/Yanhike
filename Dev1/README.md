# Yanhike Dev1

First development revision of the Yanhike board.

## Features

- ESP32-S3R8
- GNSS
- Altitude sensing
- Temperature/humidity sensing
- Magnetometer
- 6-axis IMU
- SD-card slot
- MIP display connector
- I2C display test points
